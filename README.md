# Assyabab — Pesantren Multimedia

Website profil Pesantren Multimedia Assyabab, Bogor. Prototipe presentasi dengan rancangan mobile-first, visual editorial, aksen Al-Qur'an 3D berbasis CSS, dan fotografi dari materi profil pesantren.

## Sumber konten

`Pesantren Assyabab Profile and Programs.pptx`, diberikan oleh pemilik proyek. Informasi pendaftaran merujuk brosur tahun ajaran 2026–2027 yang tercantum pada slide 34. Kuota, biaya, kontak, nama/jabatan pengajar, dan ketentuan penerimaan perlu dikonfirmasi oleh pengelola sebelum peluncuran resmi.

## Prinsip implementasi

- HTML, CSS, dan JavaScript tanpa framework runtime.
- Tidak menggunakan Three.js, video otomatis, image sequence, pelacakan, atau layanan berbayar.
- Konten utama tetap dapat dibaca tanpa JavaScript.
- Animasi menghormati preferensi pengurangan gerak; efek pointer hanya di perangkat yang mendukung.
- Foto yang dipakai berasal dari materi yang disediakan; tidak menggunakan foto stok sebagai dokumentasi pesantren.
